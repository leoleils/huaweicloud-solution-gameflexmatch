# 930版本更新

更新内容：实例规格支持选择磁盘类型，弹性伸缩支持基于会话数策略和快速扩容策略，新增服务组件性能监控；修复若干bug

更新组件：fleetmanager, aass, appgateway, auxproxy,console

## API变更

| 接口                                  | 方法         | 变更项                                         |
| ------------------------------------- | ------------ | ---------------------------------------------- |
| /{project_id}/fleets/scaling-policies | POST,GET,PUT | 新增基于可用会话数的伸缩策略，新增快速扩容策略 |
| /{project_id}/resource-specification  | POST,GET,PUT | 新增磁盘类型选项                               |



# 更新操作（830-930）

1. 数据库字段更新：

     fleetmanager数据库：

   ​       scaling_policy表，policy_type字段长度varchar(16) --> 更新为varchar(64)

2. 将fleetmanager, aass, appgateway，auxproxy和console更新至最新版本

3. 修改 /home/fleetmanager/configmap下，fleetmanager 的service_config.json 的service_endpoint，添加ces和evs的endpoint：

   ```json
   "ces_service": {"{region}": "[https://ces.{region}.myhuaweicloud.com]"},
   "evs_service": {"{region}": "[https://evs.{region}.myhuaweicloud.com]"}
   ```

4. 在aass_run.sh文件中加入

   ```shell
   export CLOUD_PlATFORM_ADDR=http://169.254.169.254
   ```
5. 重启fleetmanager，aass，appgateway和console组件
