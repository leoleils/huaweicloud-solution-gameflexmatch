## 更新步骤
### 部署
**准备阶段：拉取全部代码仓（fleetmanager、appgateway、aass、auxproxy、console）的最新代码**

1. FleetManager更新

+ 启动脚本/home/fleetmanager/bin/fleetmanager_run.sh添加环境变量

```sh
# 数据备份 自动清理fleet-server-session数据表的时间(day)
export FLEET_SERVER_SESSION_BACKUP_DAYS=1
# Redis参数，指定fleetmanager使用的redis配置
export REDIS_DB=10
# 新增workflow文件夹路径
export WORKFLOW_PATH="./conf/workflow/"
```

+ 配置文件/home/fleetmanager/configmap/service_config.json添加参数

**已验证过的公共镜像操作系统类型；可根据需要自行添加与验证**
```json
"support_public_image": {
    "cn-south-1": "CentOS 7.2 64bit,CentOS 7.9 64bit,CentOS 8.1 64bit"
}
```

+ 重新编译fleetmanager组件的二进制包，编译步骤见https://gitee.com/HuaweiCloudDeveloper/huaweicloud-solution-gamebounce/blob/master-dev/README.md 【部署指南】- 【3-文件编译】

+ 替换管理账号OBS中的image_env.sh（可选），更新将支持自定义启动Fleet应用的用户与用户组

2. AASS更新

+ 重新编译aass组件的二进制包，编译步骤见https://gitee.com/HuaweiCloudDeveloper/huaweicloud-solution-gamebounce/blob/master-dev/README.md 【部署指南】- 【3-文件编译】

3. Appgateway更新

+ appgatway启动脚本/home/appgateway/bin/appgateway_run.sh 添加环境变量

```sh
# Redis连接配置
export REDIS_ADDR=（可与FleetManager共用同个redis）
export REDIS_PASSWORD=*****
export REDIS_DATABASE=12

# 数据清理配置
export CLEAN_UP=14
export BACKUP=3
```
+ 删除上述启动脚本中二进制文件的启动参数（可选），更改后启动方法如下：

```sh
function start_service(){
        cd /home/appgateway/bin/
        ./appgateway-${version}
}
```
+ 重新编译appgateway组件的二进制包，编译步骤见https://gitee.com/HuaweiCloudDeveloper/huaweicloud-solution-gamebounce/blob/master-dev/README.md 【部署指南】- 【3-文件编译】
4. Auxproxy更新

+ 重新编译auxproxy组件的二进制包，编译步骤见https://gitee.com/HuaweiCloudDeveloper/huaweicloud-solution-gamebounce/blob/master-dev/README.md 【部署指南】- 【3-文件编译】

+ 将新编译的auxproxy二进制包以及启动脚本打包成zip压缩包，并替换管理账号OBS中的auxproxy包

5. Console更新

进入准备阶段的console项目中cd huaweicloud-solution-metaspace-console

```sh
npm install
npm install --save vue-i18n@next
npm run build
将dist 目录下的所有文件都复制到 nginx 网站根目录/usr/local/webserver/nginx/html下
systemctl restart nginx.service
```
### 使用
+ 在新版本初始使用时，需在`配置->实例规格组->新建实例规格组`中新建实例规格组，以便在新建Fleet时使用
