## 更新步骤

**注：更新后原有的fleet与新的fleet不兼容，更新或版本回退需要删除所有的fleet；**

1. 删除所有fleet，等待所有实例删除后，关闭所有运行的服务组件；

2. 在AASS数据库中确保"async_task"和"scaling_group"中的数据表中，“is_deleted”字段都为“1”，建议备份后清空表格；

3. 拉取新代码，使用go build 打包成二进制文件；

4. 更新AASS环境变量和service_config.json

   环境变量：添加redis地址，密码，redis_db；

   ```shell
   export REDIS_ADDRESS=127.0.0.1:6379
   export REDIS_PASSWORD=(GCM加密)
   export REDIS_DB=1
   
   export CLOUD_CLIENT_SMN_ENDPOINT=https://smn.cn-east-3.myhuaweicloud.com
   ```

   service_config.json：

   修改"default_configuration.monitor_duration"字段，将自动伸缩监控的事件调整为10s，新增实例健康检查时间default_configuration.health_check_interval:10，代表10s进行一次实例健康检查。

   ```json
   {
     "web": {
       "http_port": 9091
     },
     "service_endpoint": {
       "app_gateway": "192.168.0.90:60003"
     },
     "default_configuration": {
       "influx_measurement": "process",
     
       "work_node": {
         "task_over_task_interval_seconds": 300,
         "heart_beat_task_interval_seconds": 300,
         "dead_check_task_interval_seconds": 300,
         "max_dead_minutes": 10
       },
       "monitor_duration": "10s",
       "health_check_interval":10
     }
   }
   
   ```

5. 导入二进制文件，修改启动脚本对应的二进制文件名称

6. 重启所有服务。



## 委托更新

在华为云控制台，账户->统一身份认证->委托->选择所使用的委托项->授权记录，新增一条权限策略->新增SMN消息通知权限:

```json
{
    "Version": "1.1",
    "Statement": [
        {
            "Effect": "Allow",
            "Action": [
                "smn:topic:update",
                "smn:topic:create",
                "smn:topic:delete",
                "smn:topic:list",
                "smn:topic:publish"
            ]
        }
    ]
}
```
