# 730版本Readme

变更组件：Fleetmanager，AASS

## 更新内容

### 1、伸缩策略解耦

旧版：须选择一个fleet，再为其创建伸缩策略；

新版：创建策略不需要先创建fleet，通过绑定/解绑的方式与fleet关联

接口变化

| 功能                    | 新版                                                      | 变更点            |
| ----------------------- | --------------------------------------------------------- | ----------------- |
| 新建策略                | /{project_id}/fleets/scaling-policies                     | 接口url和字段变更 |
| 绑定策略                | /v1/{project_id}/fleets/scaling-policies/{policy_id}/bind | 新增接口          |
| 解绑策略                | /v1/{project_id}/fleets/scaling-policies/{policy_id}/bind | 新增接口          |
| 获取策略绑定的fleet列表 | /v1/{project_id}/fleets/scaling-policies/{policy_id}/bind | 新增接口          |
| 获取fleet绑定的策略     | /v1/{project_id}/fleets/{fleet_id}/bind                   | 新增接口          |
| 获取单个策略详情        | /{project_id}/fleets/scaling-policies/{policy_id}         | 新增接口          |



### 2、去委托

旧版：通过云服务委托的方式建立云资源

新版：通过IAM账号的ak sk直接创建云资源

| 功能                         | url                                 | 变更点   |
| ---------------------------- | ----------------------------------- | -------- |
| 管理员为用户新增租户信息     | /admin/resconfig                    | 字段变更 |
| 管理员为用户绑定已有租户     | /admin/bindres                      | 新增     |
| 管理员/普通用户 获取租户信息 | /admin/resconfig，  /user/resconfig | 字段变更 |
| 管理员修改租户信息           | /admin/resconfig                    | 字段变更 |



### 3、更新方式

停服更新，新增去委托功能不兼容原有数据库，需要建立新数据库，从头导入租户信息。

1. 备份Fleetmanager和AASS数据库
2. 关闭所有服务，修改fleetmanager数据库名为fleetmanager_old，新建数据库名fleetmanager，修改aass数据库名为aass_old，新建数据库aass；
3. 将仓库中/doc/build/fleetmanager/delete_fleet_workflow.json文件同步至fleetmanager  /conf/workflow/delete_fleet_workflow.json
4. 将各服务组件的二进制包放入测试机/home/fleetmanager/bin目录下，修改 fleetmanager_run.sh 内容，修改version=2023XXXX（以实际应用包后缀为准），保存退出；aass和appgateway同理
5. 重启服务  systemctl restart fleetmanager  ，aass和appgateway同理
6. 使用admin登录前端，密码为fleetmanager环境变量中DEFAULT_LOGIN_PASSWORD字段对应的密码；
7. 首次登录需要修改密码激活；
8. 在用户管理，账号信息页，新增租户
9. 租户名称为该项租户信息名称，项目id，ak，sk，region，密钥名等为华为云IAM账号详情的内容
10. 按照操作指导应用包管理，新建应用包
11. 在配置-实例规格组，创建一个新的实例规格组
12. 按照操作指导创建fleet
