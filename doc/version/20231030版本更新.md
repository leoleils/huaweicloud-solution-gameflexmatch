# 1030版本更新指南

## 更新内容：

1. 创建fleet时支持主域名，并在弹性伸缩活动中动态新增/删除DNS解析记录
2. 优化列表查询，部份页面支持升序/降序，所有列表页默认按创建时间降序



## API变更

1、DNS相关

| 接口                                                         | 修改内容                                    |
| ------------------------------------------------------------ | ------------------------------------------- |
| POST {project_id}/fleets                                     | 创建fleet输入参数新增“main_domain_name”参数 |
| GET {project_id}/monitor-fleets/{fleet_id}                   | 查询fleet返回结构体新增“main_domain_name”   |
| GET {project_id}/ fleets/{fleet_id} /monitor-instances       | 查询实例列表返回结构体新增“domain_name”     |
| GET {project_id}/ fleets/{fleet_id} / monitor-app-processe   | 查询进程列表返回结构体新增“domain_name”     |
| GET {project_id}/ fleets/{fleet_id} / monitor-server-session | 查询会话列表返回结构体新增“domain_name”     |
| GET {project_id}/ server-session/{server-session_id}         | 查询会话返回结构体新增“domain_name”         |

2、查询优化相关

| 接口                                     | 修改内容                                                     |
| ---------------------------------------- | ------------------------------------------------------------ |
| GET {project_id}/fleets/scaling-policies | 查询伸缩策略列表页新增query参数，支持通过伸缩策略id（scaling_policy_id），策略名称(name)和策略类型(policy_type)搜索 |
| GET {project_id}/list-enterprise         | 新增获取企业项目列表，列表内容包含企业项目id，企业项目名称，详见接口文档 |
| GET {project_id}/monitor-fleets          | 新增支持query参数order_by，支持按创建时间排序，默认降序      |

## 更新操作

1. 在fleetmanager服务 /home/fleetmanager/config/service_config.json中的service_endpoint栏添加
   
   ```json
   "dns_service": {
   	"cn-north-7": "https://dns.cn-north-4.myhuaweicloud.com"
   },
   "eps_service": {
   	"cn-north-7": "https://eps.cn-north-4.myhuaweicloud.com"
   },
   ```
   
   
2. AASS服务中/home/aass/bin/aass_run.sh中添加dns 的endpoint
   
   ```shell
   export CLOUD_CLIENT_DNS_ENDPOINT=https://dns.cn-north-4.myhuaweicloud.com
   ```
3. 更新所有服务组件，更新服务使用的auxproxy.zip文件，重建应用包

## 注：域名使用

若要使用域名，需要确保域名在华为云作接入备案，然后在华为云控制台的“云解析”服务中，在“公网域名”栏点击“创建公网域名”，添加准备好的域名，后续创建fleet时参数中填入该域名即可；

校验域名是否可用，可使用nslookup命令，或直接使用ping命令，会自动解析域名，可以查看是否能正确解析出IP



# 更早版本升级（630版本-1030版本，以北京4为例）

# 630更新1030版本操作

新增功能：

1. 去委托优化；
2. 伸缩策略解耦；
3. 创建实例支持pod；
4. 实例规格支持选择磁盘类型；
5. 新增性能监控；
6. 新增基于会话数和快速扩容策略；
7. bug修复；

## 不兼容的功能

应用包；实例规格；租户信息相关（必须重新创，然后把租户标识修改成项目id，包括fm和aass）；

## 更新步骤

操作前提：

（**重要**）确认是否支持不换库更新，进入控制台，点击用户管理-选择admin-点击资源租户信息的详情，查看**使用租户项目ID**与**资源租户项目ID**是否相同，
1. **原先使用的使用租户id(origin_project_id)和资源租户id(red_project_id)一致时才能操作**，按照Part 2操作，若不同，则建议重新创建租户，按Part 3操作；
2. 备份Fleetmanager数据库表和AASS数据库表；
3. 备份所有运行脚本：
   /home/fleetmanager/bin/fleetmanager_run.sh，
   /home/fleetmanager/bin/aass_run.sh，
   /home/fleetmanager/bin/appgateway_run.sh，
4. 备份前端console运行目录 /usr/local/webserver/nginx/html下的所有文件
5. 删除所有租户下的Fleet（必须）；
6. 准备好所有服务组件的最新应用包

### Part 1. 配置文件更新操作(基于北京四环境)

#### fleetmanager

1. /home/fleetmanager/bin/fleetmanager_run.sh
   
   增加docker image env路径
   
   ```sh
   export DEFAULT_DOCKER_SCRIPT_PATH=gameflexmatch/docker_image_env.sh # 镜像环境配置脚本 POD类型 OBS路径 桶名/对象名
   ```
2. /home/fleetmanager/configmap/service_config.json增加cci，evs，ces，dns和eps的endpoint，注意现网eps为全局
   
   ```json
   "cci_service": {
       "cn-north-4": "https://cci.cn-north-4.myhuaweicloud.com"
   },
   "swr_service": {
       "cn-north-4": "https://swr-api.cn-north-4.myhuaweicloud.com"
   },
   "evs_service": {
       "cn-north-4": "https://evs.cn-north-4.myhuaweicloud.com"
   },
   "ces_service": {
       "cn-north-4": "https://ces.cn-north-4.myhuaweicloud.com"
   },
   "dns_service": {
       "cn-north-4": "https://dns.cn-north-4.myhuaweicloud.com"
   },
   "eps_service": {
       "cn-north-4": "https://eps.myhuaweicloud.com"
   },
   ```
   
   增加docker支持的镜像(与endpoint同级)
   
   ```json
   "support_docker_based": {
       "cn-north-4": "centos:7.6.1810,centos:7.2.1511"
   },
   ```
3. 同步workflow文件
   
   将/home/fleetmanager/bin/conf/workflow目录下的文件删除，并替换成汇总仓库中/doc/build/fleetmanager下的以下文件：
   
   ```
   create_build_docker_image_workflow.json  
   create_build_image_workflow.json
   create_fleet_cci_pod_workflow.json
   create_fleet_workflow.json
   delete_fleet_cci_workflow.json
   delete_fleet_workflow.json
   ```

#### AASS

1. aass_run.sh 增加endpoint
   
   ```
   export CLOUD_CLIENT_CCI_ENDPOINT=https://cci.cn-north-4.myhuaweicloud.com
   export CLOUD_CLIENT_DNS_ENDPOINT=https://dns.cn-north-4.myhuaweicloud.com
   ```

## 备注：
关于DNS
1、使用DNS功能需要域名备案；
2、添加主域名后服务进程无法拉起时，尝试更改DNS解析地址
```shell
vim /etc/resolv.conf
# 修改第一个nameserver为114.114.114.114 或其他
nameserver 114.114.114.114
# wq保存退出
```
保存退出后，使用ping命令ping域名，查看是否能解析出IP地址，或者使用nslookup（需要安装dnsutils）
```shell
nslookup xxxx.gameflexmatch.com
```
