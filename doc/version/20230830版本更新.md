# 830版本更新

新增功能：支持创建pod实例，支持创建swr镜像，支持创建pod实例规格

更新组件：fleetmanager, aass, appgateway, auxproxy,console

## API变更

| 接口                                 | 方法     | 变更项                                                 |
| ------------------------------------ | -------- | ------------------------------------------------------ |
| /{project_id}/fleets                 | POST     | 新增instance_type，支持VM和POD                         |
| /{project_id}/fleets                 | GET      | 新增instance_type，支持VM和POD                         |
| /{project_id}/image-builds           | POST     | 新增build_type，支持VM和POD                            |
| /{project_id}/builds                 | GET,POST | 新增build_type，支持VM和POD                            |
| /{project_id}/resource-specification | POST     | 新增instance_type，支持VM和POD，以及pod实例cpu和内大小 |
| /{project_id}/resource-specification | GET      | 新增instance_type，支持VM和POD                         |

## 更新操作(730-830)

1. 数据库字段更新：
   
   fleetmanager数据库表字段长度变化（手动修改）
   
   build  operating_system imageid 50 -> 256
   
   build_image imageid 50 -> 256
   
   fleet operating_system 50 -> 256
2. 应用包更新
3. 将fleetmanager, aass, appgateway 更新至最新版本，修改启动脚本内的应用包版本；
4. aass运行脚本aass_run.sh中添加
   
   ```shell
   export CLOUD_CLIENT_CCI_ENDPOINT=https://cci.cn-north-7.myhuaweicloud.com
   ```
   
   修改 /home/fleetmanager/configmap下，fleetmanager 的service_config.json    的service_endpoint，添加cci的endpoint
   
   ```json
   "swr_service": {
         "cn-north-7": "https://swr-api.cn-north-4.myhuaweicloud.com"
   },
   "cci_service": {
       "cn-north-7": "https://cci.cn-north-4.myhuaweicloud.com"
   }
   ```
5. 重启所有服务组件；
6. 进入console控制台，重新打包VM和POD应用包，创建VM和POD实例规格；
7. 创建fleet

   ```json
   "swr_service": {

   },
   "cci_service": {
       "cn-north-4": "https://cci.cn-north-4.myhuaweicloud.com"
   ```
