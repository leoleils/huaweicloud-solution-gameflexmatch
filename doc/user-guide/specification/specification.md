# 创建实力规格组

gamebounce平台支持预先创建实例规格组模板，在创建fleet提供选择

![实例规格组](../../../img/specification/create_spec_input.jpg)



## 创建VM实例规格组

针对创建fleet为ECS类型的实例规格，相同规格下支持选择最多10种型号，创建fleet时会按照选择的规格优先顺序进行创建；

![实例vm规格组](../../../img/specification/select_vm_spec.jpg)





## 创建Pod实例规格组

支持创建pod类型的规格组，支持选择pod实例的CPU和内存大小


![实例pod规格组](../../../img/specification/select_pod_spec.jpg)



## 使用实例规格组

以VM为例，在创建fleet时选择刚创建的实例规格![使用vm实例规格组](../../../../../metaspace/huaweicloud-solution-metaspace/img/lts/use_vm_spec.jpg)
