# 别名管理

## 创建别名

### 操作场景
可以为应用进程队列(fleet)创建别名(alias)，使用aliasId代替fleetId创建会话，以完成灰度发布的更新过程，并可以为不同的fleet配置不同的权重，加权分配不同的会话创建请求

### 创建须知
需保证alias关联的fleet均为激活状态，每个fleet的权重为相对权重，取值范围[0,100]整数

### 操作步骤
1. 登录`gamebounce`管理控制台
2. 选择`Fleet管理->别名管理->新建别名`
![create-alias](../../../img/alias/create-alias.jpg)
3. 填写必要参数
   
    |   参数    |                                       描述                                       |  类型  |
    | :-------: | :------------------------------------------------------------------------------: | :----: |
    | 別名名称  | 别名名称(1~1024个字符)，以英文字母开头，并由英文字母、数字、下划线和中划线组成。 | string |
    |   描述    |                              别名的描述(1~1024字符)                              | string |
    |   类型    |          别名的类型(激活类型/停用类型)，激活类型的别名可以用于创建会话           |  enum  |
    |   消息    |        别名消息，当使用停用类型的别名创建会话时，会返回该消息(1-1024字符)        | string |
    | 关联Fleet |         选择alias所需要关联的fleet，以及设定该fleet的权重，最多关联10个          | array  |
    | Fleet ID  |                            关联的fleet的id，32位uuid                             | string |
    |   权重    |                                   取值为0-100                                    |  int   |

4. 参数配置完成后，单击“创建”，即可完成创建

## 修改别名
### 操作场景
当需要对别名的名称、描述、类型、消息以及关联的fleet增删改操作的时，可对别名进行修改操作
当别名中关联的fleet状态改变不为激活状态，但需要将该别名类型修改为激活时，需要执行修改操作

### 操作步骤
1. 登录`gamebounce`控制台
2. 选择`Fleet管理->别名管理`，选择要修改的别名
3. 根据实际情况进行修改，修改关联fleet时，只支持修改权重

## 查询别名
### 操作场景
需要对别名进行筛选查询，现在支持通过别名名称、类型以及关联的fleet进行筛选

### 操作步骤
1. 登录`gamebounce`控制台
2. 选择`Fleet管理->别名管理`
3. 点击搜索框
4. 出现`按照fleet_id进行搜索`、`按照别名名称进行搜索`、`按照别名类型进行搜索`，按照实际情况选择


## 删除别名
### 操作场景
当某条别名不再使用时，需要进行删除操作

### 操作步骤
1. 登录`gamebounce`控制台
2. 选择`Fleet管理->别名管理`，选择要删除的别名，点击删除
3. 在弹出的确认对话框中，点击确定即可完成删除操作
